# Security Policy

## Supported Versions

EchoFoundry is an actively developed solo research project, not yet at a stable/tagged release. There is no formal versioning scheme yet.
This will be updated once the project reaches a first tagged release (e.g., `v1.0`) with a real support window.

## Reporting a Vulnerability

If you find a security issue in this project (e.g., credential handling, SQL injection risk in the ingestion/API layers, dependency vulnerabilities, or exposed secrets), please **do not open a public GitHub issue**.

Instead, report it privately using one of the following:

- **Preferred:** Use GitHub's private vulnerability reporting — go to the **Security** tab of this repository → **Report a vulnerability**.
- **Alternative:** Email **brandonabegglen06@gmail.com** with a description of the issue, steps to reproduce, and potential impact.

**What to expect:**
- Acknowledgment of your report within **5 business days**.
- A status update within **2 business days** of acknowledgment.
- If accepted, a fix will be prioritized and you'll be credited in the fix commit/notes unless you prefer to remain anonymous.
- If declined, you'll receive an explanation of why it was deemed out of scope or not a valid vulnerability.

This is a student research/portfolio project rather than a production system handling real user data or capital, so please keep severity expectations calibrated accordingly, but reports are genuinely welcome and appreciated!
